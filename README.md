 This project generates MCQs from user-input text using spaCy for Named Entity Recognition and OpenAI’s GPT-4o-mini via prompt engineering. It features an interactive UI built with Streamlit (or Gradio) that allows users to answer the question and receive instant feedback.

💡 Tech Stack: Generative AI (LLMs), Python
🔑 Note: To run this project, enter your OpenAI API key.
